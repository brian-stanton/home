# home

My house, built by [ansible](https://docs.ansible.com/)

```bash
./ansible/install              # this machine, everything
./ansible/install core         # portable env (zsh, tmux, neovim, git, …)
./ansible/install core desktop # portable env + alacritty / Linux WM
./ansible/install neovim       # just neovim
./ansible/install mac neovim   # require macOS
./ansible/install linux        # require Ubuntu
```

See [ansible/README.md](ansible/README.md).

Used some code from public repos [ansible](https://github.com/ThePrimeagen/ansible) and [dev](https://github.com/ThePrimeagen/dev)
